# Women Safety & Emergency Assistance Platform

A full-stack MERN-based web application designed to provide immediate emergency assistance for women through one-click SOS alerts, real-time location sharing, volunteer coordination, and incident tracking.

## Features

### User Features

* Secure User Registration & Login
* Personal Safety Profile
* Add Trusted Emergency Contacts
* One-Click SOS Emergency Alert
* Real-Time Location Sharing
* Emergency Alert History
* Live Incident Tracking

### Volunteer Features

* Volunteer Registration
* Verification System
* Receive Nearby Emergency Alerts
* Accept/Decline Assistance Requests
* View User Location
* Update Response Status

### Admin Features

* Manage Users & Volunteers
* Verify Responders
* Monitor Active Incidents
* Manage Safe Zones
* Generate Reports & Analytics

## Tech Stack

### Frontend

* React.js
* React Router DOM
* Axios
* Tailwind CSS
* Leaflet Maps
* Socket.IO Client

### Backend

* Node.js
* Express.js
* Socket.IO
* JWT Authentication

### Database

* MongoDB Atlas

## Installation

### Clone Repository

```bash
git clone https://github.com/Shivam05-sys/Raksha-Safety
cd Raksha-Safety

## Backend Setup
Navigate to backend folder:

```bash
cd backend
```

Install dependencies:
```bash
npm install
```
Create a `.env` file:

```env
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_secret_key
PORT=5000
```
Start backend server:

```bash
npm start
```

Backend will run on:
http://localhost:5000

## Frontend Setup

Navigate to frontend folder:
cd frontend
Install dependencies:
npm install

Start frontend:
npm run dev

Frontend will run on:
http://localhost:5173
